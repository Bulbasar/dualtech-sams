IST Portals · Trainee Portal

Trainee Portal
trainee.html

React 18 Firebase Auth PWA

Secure, multi-factor onboarding that verifies trainees against the official masterlist before account creation — with biometric enrollment, GPS-verified attendance, and schooling submissions.

Portal Link: https://dualtech-ojt-portal.web.app/trainee
Updates: 631 registered trainees, 65 partner companies. Created GC to address rollout and implementation concerns.

🔍
Masterlist Verification
+

Trainees search by Student ID. Only records marked "Active", "Completed IPT", or "Post-BSTP" in the Firestore masterlist can register. Duplicate registration is automatically blocked.

📲
Biometric Login (WebAuthn)
+

Fingerprint / FaceID setup during registration using the WebAuthn API. Stored credentials enable 1-tap sign-in on mobile devices — no passwords needed for daily use.

📍
Geofenced Clock-In/Out
+

Uses the Haversine formula to calculate distance between the trainee's GPS coordinates and the assigned company location. Clock-in is only permitted within the allowed proximity radius. Full attendance history with hours tracking.

📱
QR Schooling & Online Submissions
+

Dual-mode schooling attendance: QR-based scanning for on-site meetings and form-based uploads for online assignments (VFL, LSCE, DR Entry). Weighted meeting credits for PDS and Retreats.

🏆
Diligence Report & Profile
+

Tracks and displays a trainee's diligence score, attendance rate, and training performance metrics. Profile management with contact info, emergency contacts, and password/security settings. PWA-enabled with offline persistence.

Additional Portals · Mentoring

Mentoring Portals
mentoring.html · schooling.html

React 18 Firestore Recharts PapaParse

Two interconnected portals for managing online schooling and mentoring activities.

Mentoring Manager/Admin: https://dualtech-ojt-portal.web.app/mentoring
Mentors' Portal: https://dualtech-ojt-portal.web.app/schooling

⚠️
Problem Statement
+

Unreliable QR Data: Current QR code data is sometimes unreliable because mentors forget to scan, students lack issued codes, or phone data is unavailable.

Bulk Submissions: Trainees often exploit the current system by submitting several weeks' worth of activities in a single day, despite the presence of timestamps.

💡
Proposed Solution
+

Submissions will be done in the trainee's portal. The Mentoring Manager/Administrator (mentoring.html) will set activities for online schooling with automated deadlines, preventing one-time bulk submissions.

QR scanning will be done by trainees scanning the mentor's QR — reversing the current flow for better reliability.

📊
Admin Dashboard (mentoring.html)
+

Live KPI cards showing Active Trainees, Registered Mentors, and Available Venues. Interactive calendar for scheduling sessions. Mentor & venue management via Firebase Auth. Schooling assignment with bulk operations. Online submission review (VFL, LSCE, DR Entry). PDS & Retreat activity logs.

🎓
Mentor Portal (schooling.html)
+

Dedicated interface for mentors to manage their assigned trainees, view schedules, generate QR codes for trainee scanning, and track per-trainee schooling compliance across 18 training months with weighted activity credits. CSV export and bulk import via PapaParse.

📅
Implementation Timeline
+

August 1, 2026 — Target launch date for online schooling activities with automated deadline enforcement through the trainee portal.

Proposed System · ID Printing

Proposed ID Printing
System Portal

Portal Link: https://dualtech-ojt-portal.web.app/idprinting

⚠️
Problem Statement
+

Current set-up takes 2 to 3 weeks to print ID, with 3 to 5 days of manual checking and verification prior to the meeting.

Reference: Minutes Meeting: II. Identified Concerns & Bottlenecks

💡
Proposed Solution
+

Revised ID Printing System Interface — a fully digital workflow with live PVC card preview, batch processing, signature capture, QR codes, and direct email delivery to eliminate manual bottlenecks.

📅
Implementation Timeline
+

W1 August 2026 — For Approval by ETDC, LMC, and RVSA.

Proposed System · ID Printing Features

Student ID Card
Printing System

Vanilla JS Google Apps Script html2pdf.js

A specialized registrar tool for designing, printing, and batch-managing PVC student ID cards with live preview, signature capture, QR codes, and email delivery.

🪪
Live ID Card Preview
+

PVC-accurate 2.125" × 3.375" live preview showing both front (photo, nickname, full name, student #) and back (QR code, address, contacts, validity year). All fields update in real-time as you type.

✍️
Signature Pad & Photo Upload
+

HTML5 Canvas-based signature pad supporting mouse and touch input. ID photo upload with circular crop. Both appear on the front card in real-time. Auto-calculated validity (enrollment + 2 years) with manual override.

🖨️
Direct PVC Printing
+

Print-optimized CSS with exact PVC card dimensions, zero margins, and automatic page breaks per card face. Each front and back prints on its own page at full bleed.

📦
Batch Processing
+

Load all student records from Google Sheets. Select individuals via checkboxes, toggle preview, then batch print, batch export to PDF, or batch email — all in one workflow.

📧
Email ID Cards (PDF)
+

Generate high-resolution PDF (6× scale) → encode as Base64 → send directly to student email via Google Apps Script backend. Supports single and batch email delivery with progress tracking.

🔍
Search, Update & Delete (CRUD)
+

Search existing records by Student ID or name via the Google Apps Script backend. Load into form for editing, then update or delete records. QR code on the back links to a verification endpoint.
